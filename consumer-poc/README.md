# OITV Consumer POC — Leoness

This is an isolated Next.js/React proof of concept for the future Out in the Vines consumer experience.

## Purpose
- Prove the Founder’s Edition experience can be rebuilt without porting its static runtime.
- Render one winery from a typed consumer contract.
- Establish mobile-first hierarchy before connecting certified Vinny Intelligence.
- Provide one real page for the Payload vs. Plasmic vs. Builder hands-on bakeoff.

## Safety boundary
This POC does not connect to Vinny production, Supabase, or the old data.js runtime. All Leoness content here is mock/reference content. Unresolved governed facts intentionally remain unresolved.

## Run locally
```bash
cd consumer-poc
npm install
npm run dev
```
